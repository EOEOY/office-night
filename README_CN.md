# 深夜办公室·打工人怪谈

喜剧向职场怪谈内容包：**加班到 23:00 的写字楼开始闹鬼**。电梯停在第 13 层，茶水间的咖啡会说话，打印机吐预言，KPI 满 100 就能转正——但转正之前，得先活着。

## 怎么用（三步）

1. **装包**：设置页 → 插件 → 导入 `office-night-1.2.0.dfplugin`
2. **启用**：在插件列表打开这个包的开关
3. **开玩**：创建游戏时选择「深夜写字楼」世界与「深夜办公守则」规则

## 检定规则

- 只有结果不确定且存在风险的摸鱼、汇报、逃生或对抗才检定；普通聊天和已经完成的工作不重复掷骰。
- 检定使用 `d20 + 属性修正 + 技能加值` 对抗 DC；自然 20 为大成功，自然 1 为大失败，DC 最高为 20。
- 优势/劣势掷 2d20 并取高/取低；另一名角色提供有效协助时，本次检定获得优势。
- 旧存档无需转换；更新并启用同一规则 ID 的新版内容包后即可继续游玩。

## 核心玩法

- **加班值（overtime）**：满 100 触发『猝死』——不是玩笑，是规则；活着下班就是胜利
- **老板信任（boss_trust）**：高信任解锁资源、请假条与免死金牌；低信任会被叫去『聊一聊』
- **KPI**：满 100 触发『转正』结局——但深夜述职会，参会者只能进不能出
- **深夜事件**：按楼层触发，电梯是最危险的地点；第 13 层藏着你们所有人的入职合同

## 内容清单

- **规则**：深夜办公守则（六维：发际线/摸鱼力/智商/甩锅/血压/社牛 + 加班值/老板信任/KPI）
- **世界**：深夜写字楼，**10 条世界书自动进对局**（13 层、会说话的咖啡、预言打印机、老板/甄姐/兰姨/老周）
- **角色卡**：程序员陈码、产品图图、HR 甄姐、实习生阿新
- **NPC**：王总、甄姐、兰姨、老周、幽灵同事、隔壁卷王 Alex
- **道具**：特浓咖啡、降噪耳机、甩锅 U 盘、加班毯
- **职场异能**：甩锅术、摸鱼结界、汇报美化、强制下班
- **职业**：程序员、产品经理、HR、实习生

## 给 GM 的建议

- 喜剧优先：让咖啡机吐槽、让打印机预言、让幽灵同事帮你改 bug
- 深夜事件别太密，留出『摸鱼聊天』的空间——笑点都在对话里
- KPI 是双刃剑：转正听起来是好事，但述职会……你自己看着办
- 第 13 层是主线：档案室里那份 20 年前的合同，是所有故事的答案

## Content V2 与世界书可见性

- 需要 DiceFrame 2.5.0 或更高版本。
- 本版本使用 DiceFrame Content V2：资源 ID 保持 canonical，规则与世界均声明独立 schema。
- 世界书条目显式区分全队可见与 GM 私密；谜底、反转和未发现的异常不会提前显示给玩家。
- 内容包为中文单语言包，`default_locale` 为 `zh-CN`；后续翻译应放入 typed locale overlay，不得修改规则机制。
